# news-image-20261123

A newspaper front page summing up the world's news of Monday 23 November 2026 in one image: Ukraine's sea-drone sinking of the Russian corvette Merkury off Libya, COP31 ending with no deal, NATO's emergency meeting over Russian missiles in Poland, the Asian chip-stock slide (Kospi −3.3%), the deadly candy-factory fire in Indonesia (24 dead), and the launch of the Trump Route (TRIPP) in Armenia — plus a ticker with the Dymer toll rising to 11 and Iran's vow over the US naval blockade.

Every story was verified against live reporting dated 23 November 2026 (Reuters, AP, CNN, Korea JoongAng Daily, RIA Novosti) before it was drawn. `gen_image.py` drew `entry.png` at build time with Pillow; `main.py` (Python 3.13, standard library only) copies it to the output directory.

Built for the [news-image-20261123 bounty on make.fun](https://make.fun/bounty/news-image-20261123).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
